PAIR About Try it

PAIR predicts the correlation between two questionnaire items from their wording.

Method
1
Embed each item

Every item is encoded with Qwen3-Embedding-8B, using an instruction that asks the model to represent the item's latent psychological constructs.

2
Predict each pair

A siamese neural network takes two item embeddings and predicts the correlation r between responses to them.

3
Derive scale statistics

Scale-level results are computed analytically from the predicted item correlations.

r(A,B) = Cov(ΣA, ΣB) / √(Var(ΣA) · Var(ΣB)) α = n/(n−1) · (1 − n / (n + 2Σ|rij|))
Validity evidence
r.785
MAE.097
RMSE.128

Agreement between predicted and observed item correlations on the validation set of Hommel and Arslan (2025): 31,125 item pairs from 20 scales not seen in training, using Qwen3-Embedding-8B with the siamese network.

Reference

Hommel BE, Arslan RC. Language Models Accurately Infer Correlations Between Psychological Items and Scales From Text Alone. Advances in Methods and Practices in Psychological Science. 2025;8(4). doi:10.1177/25152459251377093
